# Tab Content Rotator Chrome Extension

This Chrome extension allows you to rotate tab content, particularly useful for video calls when someone's screen is rotated and you need to view it properly on your laptop.

## Features

- Rotate videos or entire web pages by 90°, 180°, or 270°
- Choose between rotating only video elements or the entire page
- Simple, intuitive user interface
- Works on most websites including video conferencing platforms

## Installation

Since this extension is not published to the Chrome Web Store yet, you'll need to install it in developer mode:

1. Download or clone this repository to your computer
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" by toggling the switch in the top-right corner
4. Click "Load unpacked" and select the extension folder
5. The extension should now appear in your Chrome toolbar

## How to Use

1. Navigate to the webpage containing the video call or content you want to rotate
2. Click the Tab Content Rotator icon in your Chrome toolbar
3. In the popup menu, select your preferred rotation angle:
   - 90° Clockwise
   - 180°
   - 90° Counter-Clockwise
4. Choose whether to rotate only videos or the entire page
5. To reset the rotation, click the "Reset Rotation" button

## Use Cases

- Video calls where the other person's camera is rotated
- Viewing sideways content without having to physically rotate your device
- Correcting orientation issues in embedded videos

## Troubleshooting

If the rotation doesn't work properly:

- Try refreshing the page and applying the rotation again
- Some websites with strict Content Security Policies may block the extension
- For complex web applications, try rotating the entire page instead of just videos

## Privacy

This extension only modifies the visual presentation of web content. It does not:
- Collect any user data
- Transmit information to any servers
- Modify the actual content of websites
